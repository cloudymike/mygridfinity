# README for cabinet drawer plates


## Hardware required

### Connecting the plates together
* M3 nut
* M3 X 8mm screw

### Connecting plates to frame
* M3 X 10mm knurl
* M3 X 12mm screw

## Tools required

* Allen wrench 2mm
* baseplates/nutholder.scad
	This is a tool to hold the M3 nut in place whild screwing together the plates.
